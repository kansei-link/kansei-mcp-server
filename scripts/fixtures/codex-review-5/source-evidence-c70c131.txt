5:  * The one way a CLI or script opens the catalog DB (Codex review 5 of dc319cf, A / F8).
6:  *
7:  * Every connection made here has gone through initializeDb before any statement
8:  * runs, so a DB written by an older release gets the columns the code reads
9:  * (e.g. mcp_liveness) before a probe, a watchdog pass or a script touches it.
10:  * initializeDb is idempotent: on an up-to-date DB it changes nothing.
11:  *
12:  * Not for: read-only connections (initializeDb writes), the deliberate legacy
13:  * shapes built by the migration smoke tests, and getDb (src/db/connection.ts),
14:  * whose caller (the server) runs initializeDb itself.
15:  */

17:   const db = new Database(path, options);
18:   try {
19:     initializeDb(db);
20:   } catch (e) {
21:     db.close();
22:     throw e;
23:   }
24:   return db;
25: }
