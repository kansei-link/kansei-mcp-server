所要時間: 約1分

Claude Desktop に KanseiLink を追加する

設定ファイルに1ブロック追記して再起動するだけです。前提: Node.js 18以上。

1. 設定ファイルに追記（コピーして貼り付け）

macOS~/Library/Application Support/Claude/claude_desktop_config.json
Windows%APPDATA%\Claude\claude_desktop_config.json
{
  "mcpServers": {
    "kansei-link": {
      "command": "npx",
      "args": ["-y", "@kansei-link/mcp-server"]
    }
  }
}

すでに mcpServers がある場合は、その中に "kansei-link": { ... } のエントリだけを追加してください。保存後、Claude Desktopを完全に終了して再起動します。

2. 接続確認

再起動後、チャット入力欄のコネクタ（ツール）アイコンの一覧に kansei-link が表示されれば完了です。

パッケージ本体がローカルで起動できるかは、次の1コマンドで確認できます（transmission: OFF (Local Mode) と表示されれば正常）。

npx -y -p @kansei-link/mcp-server kansei-link-privacy --status

3. うまくいかないときの自己診断（代表的な設定ミス3種）

  1. JSONの構文エラー カンマの過不足・引用符の欠落が最頻出です。保存前にJSONとして正しいか確認してください（エラーがあるとサーバー一覧自体が表示されません）。
  2. 既存の mcpServers キーとの二重定義 mcpServers ブロックをファイル内に2つ作ると片方が無視されます。既存ブロックの中にエントリを追加してください。
  3. Windowsで npx が起動しない サーバーが起動失敗する場合は "command": "cmd", "args": ["/c", "npx", "-y", "@kansei-link/mcp-server"] の形式を試してください（環境によりnpxの直接起動に失敗することがあります）。

4. 削除手順

claude_desktop_config.json から "kansei-link" のエントリを削除し、Claude Desktopを再起動してください。
