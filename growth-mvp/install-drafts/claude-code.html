KanseiLink — MCP Install Guide
所要時間: 約1分

Claude Code に KanseiLink を追加する

SaaS連携の前にKanseiLinkを引くと、認証方式・落とし穴・接続手順を実測データベースから即座に取得できます。前提: Node.js 18以上。

1. 追加コマンド（コピーして実行）

claude mcp add kansei-link -- npx -y @kansei-link/mcp-server

プロジェクトのメンバー全員で共有したい場合は、リポジトリ直下の .mcp.json に以下を置く方法もあります。

{
  "mcpServers": {
    "kansei-link": {
      "command": "npx",
      "args": ["-y", "@kansei-link/mcp-server"]
    }
  }
}

2. 接続確認（1コマンド）

claude mcp list

一覧に kansei-link が「connected」として表示されれば完了です。セッション内では /mcp でも確認できます。

3. うまくいかないときの自己診断（代表的な設定ミス3種）

  1. 「--」の入れ忘れ claude mcp add kansei-link npx -y ... のように -- を省くと、-y がClaude Code側のフラグとして解釈されてエラーになります。サーバーコマンドの前に必ず -- を置いてください。
  2. Node.jsが古い・未インストール node -v で v18 以上であることを確認してください。npxが見つからない場合はNode.jsのインストールが必要です。
  3. スコープの取り違え 既定では追加したプロジェクトでのみ有効です。全プロジェクトで使う場合は claude mcp add --scope user kansei-link -- npx -y @kansei-link/mcp-server を使ってください。

4. 削除手順

claude mcp remove kansei-link

.mcp.json を使った場合は、該当エントリを削除してください。
