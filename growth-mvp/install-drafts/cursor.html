KanseiLink — MCP Install Guide
所要時間: 約1分

Cursor に KanseiLink を追加する

mcp.json に1ブロック置くだけです。前提: Node.js 18以上。

1. mcp.json を作成（コピーして貼り付け）

プロジェクト単位リポジトリ直下の .cursor/mcp.json
全プロジェクト共通~/.cursor/mcp.json
{
  "mcpServers": {
    "kansei-link": {
      "command": "npx",
      "args": ["-y", "@kansei-link/mcp-server"]
    }
  }
}

2. 接続確認

Cursor Settings → MCP を開き、kansei-link が有効（ツール一覧に search_services / lookup / report が表示）になっていれば完了です。

パッケージ本体がローカルで起動できるかは、次の1コマンドで確認できます（transmission: OFF (Local Mode) と表示されれば正常）。

npx -y -p @kansei-link/mcp-server kansei-link-privacy --status

3. うまくいかないときの自己診断（代表的な設定ミス3種）

  1. ファイルの置き場所違い プロジェクト設定は「リポジトリ直下の .cursor/mcp.json」です。.cursor ディレクトリの外や、別階層に置くと読み込まれません。
  2. JSONの構文エラー カンマの過不足・引用符の欠落があると読み込みに失敗します。設定画面にサーバーが出てこない場合は、まずJSONの妥当性を確認してください。
  3. MCP機能が無効のまま Cursor Settings → MCP でMCP自体が無効になっていると、mcp.jsonが正しくても起動しません。設定でサーバーのトグルがONかを確認してください。

4. 削除手順

mcp.json から "kansei-link" のエントリを削除してください（ファイルごと削除しても構いません）。

Live Updates（利用データの送信を伴う更新通知）は任意・デフォルトOFFです。有効化する場合のみ、同意文（README「Live Updates」節）をご確認ください。
