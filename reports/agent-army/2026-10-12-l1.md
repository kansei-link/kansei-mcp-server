## Notes

- All failures share error type `endpoint_unreachable`.
- **"fetch failed" pattern** (network TCP/TLS failure, no HTTP status): Affects primarily well-known SaaS APIs (Slack, Jira, GitHub Actions, Asana, Zapier, Salesforce, etc.). - **HTTP 404 pattern**: Affects GitHub-hosted MCP server repos (smithery.ai mirrors, small community projects). These are more likely genuine link rot — repos deleted, renamed, or moved.
- **Recommendation**: Re-run from an environment without outbound HTTP restrictions to validate "fetch failed" entries before taking action. Flag HTTP 404 entries for catalog cleanup.
