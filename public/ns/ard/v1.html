VOCABULARY · v1

kansei: 名前空間

名前空間の IRI は https://kansei-link.com/ns/ard/v1#。JSON-LD の context は /ns/ard/v1.jsonld。

語

語名前意味
kansei:verificationLevel記録の段階L0 存在確認（一次資料で公式 MCP を確認）／L1 到達確認（封印した問いで毎日測った）／L2 接続確認（起動・接続して操作定義を取得）／L3 業務完了確認。L0 は「検証済み」ではない。
kansei:verifiedOn確認日その段階を確かめた日（L0 は一次資料を開いた日）。
kansei:verifiedUntil有効期限この記録を確かめ直す期限。期限を決めていない記録には付けない。
kansei:evidence証拠L1 以上の記録の裏付け（測る前に封印した正解の指紋など）の URL。L0 には付かない。
kansei:author作成主体この記録を書いた主体。
kansei:verifier検証主体L1 以上を確かめた主体。L0 には付かない。
kansei:sourceAnnouncement一次資料公式 MCP の存在を確認した、提供者自身の発表・文書の URL。
kansei:hosting提供形態self-hosted-local（利用者の手元で実行）／self-hosted-remote（利用者が自分でリモートに設置）／vendor-hosted（提供者が運用）／unclear（一次資料に記載なし）。
kansei:authMethod認証方式一次資料に書かれた認証方式。unclear は一次資料に記載なし。
kansei:useCaseGroup用途の束用途で分けた束。順位ではない。
kansei:failures現場メモエージェントが実務で詰まった記録（機械可読）の URL。

これらの語は /.well-known/ard.json のエントリで使っています。人間向けの一覧は /ard/。
