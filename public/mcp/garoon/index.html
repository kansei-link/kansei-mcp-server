Garoon MCP｜公式サーバーの有無とつなぎ方（2026年10月時点）

Garoon（サイボウズ株式会社）の公式 MCP サーバーについて、2026-10-22 に一次資料で確かめた範囲を書いています。

公式 MCP あり
Garoonには、提供元のサイボウズ株式会社が公開する公式の MCP サーバーがあります（2026-10-22 確認）。 kintone とは別の、Garoon 専用のローカル MCP サーバーです。

公式 MCP サーバーの所在とつなぎ方

提供元サイボウズ株式会社
所在リポジトリ: https://github.com/garoon/garoon-mcp-server
npm @garoon/mcp-server（2026-10-19 時点 1.3.1）・Docker イメージ・Claude for desktop 向け MCPB も配布
提供の形自分の環境で動かす（ローカル）
stdio で動くローカルサーバー。提供元が運用するリモート版は公式の情報にはありません。
認証方式Garoon のログイン名とパスワードを環境変数（GAROON_USERNAME / GAROON_PASSWORD）で渡す。必要に応じて Basic 認証のユーザー名・パスワードと、セキュアアクセス用のクライアント証明書（pfx）も環境変数で指定。
cybozu.dev の文書は認証方式に触れておらず、README に書かれています。README には「ログイン情報を含む設定ファイルを保存することはセキュリティ上のリスクがある」旨の注意があります。OAuth の記載はありません。
公式の手順garoon-mcp-server README（公式の告知が使い方の文書として案内）
但し書きすべてのリクエスト／レスポンスのパラメーターには対応していない。API サポート窓口の対象外で、不具合や要望は GitHub Issues へ。DB 分割構成は非対応。Claude for desktop・Cursor・VS Code の設定例あり。

手順そのものは提供元の文書に従ってください。ここには写しません。認証方式は README だけでなく、提供元の文書全体から読み取った範囲で書いています。

詰まりどころ

このサービスについての現場メモは、まだありません。

Garoon のエラーで止まったら: GET https://kansei-link-mcp-production.up.railway.app/api/v1/ask?service=garoon&error=<短いエラー文> で、確認済みの解決策（あれば）と公式ドキュメントが返ります。読み取りだけで、何も公開されません。エラー文に鍵やトークンを入れないでください。長い文は同じ欄を JSON で POST。
