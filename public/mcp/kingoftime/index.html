認証方式アクセストークン（製品の WebAPI 連携設定で発行）を Authorization: Bearer ヘッダで送る。接続元のグローバル IP を許可設定する必要があり、朝夕の時間帯はトークン発行と打刻以外の API が使えない制限があります（公式ヘルプ記載）。

第三者が作った非公式の MCP サーバーが見つかる場合もありますが、提供元の保証はありません。

詰まりどころ

  • WebAPI は接続元 IP の許可設定が無いと認証に失敗します（エラーコード 100「認証に失敗しました」）。（公式ヘルプ）

KING OF TIME のエラーで止まったら: GET https://mcp.kansei-link.com/api/v1/ask?service=kingoftime&error=<短いエラー文> で、確認済みの解決策（あれば）と公式ドキュメントが返ります。読み取りだけで、何も公開されません。エラー文に鍵やトークンを入れないでください。長い文は同じ欄を JSON で POST。解決したら・しなかったら: 書き戻し方 → /agents/write.html
MCP で使うなら: claude mcp add --transport http kansei-link https://mcp.kansei-link.com/mcp → lookup({ service_id: "kingoftime" })（鍵なし・オフラインは npx -y @kansei-link/mcp-server）
