Misoca MCP｜公式サーバーの有無とつなぎ方（2026年10月時点）

Misoca（弥生株式会社）の公式 MCP サーバーについて、2026-10-22 に一次資料で確かめた範囲を書いています。

公式 MCP あり
Misocaには、提供元の弥生株式会社が公開する公式の MCP サーバーがあります（2026-10-22 確認）。 対象は Misoca の有償プラン契約者で、ベータ機能としての提供です。

公式 MCP サーバーの所在とつなぎ方

提供元弥生株式会社
所在接続先: https://mcp.misoca.jp/mcp
公式サポートページに「リモートMCPサーバーURL」として記載。リポジトリはありません
提供の形提供元が運用するサーバーに接続する（リモート）
Claude の「カスタムコネクタ」として登録する形。他の AI ツールは各ツールの案内に従って同じ URL を登録。
認証方式OAuth（Claude のコネクタ設定で認証「常に必須」・OAuth クライアント「クライアントIDなし－自動的に登録する」を選び、Misoca にログインして連携を承認する）。操作範囲はログインしているユーザーの Misoca アカウントの権限内。
プレスリリースと機能ページには認証方式の記載がなく、公式サポートページ「Misoca MCPを利用する」にだけ書かれています。
公式の手順弥生サポート: Misoca MCPを利用する
但し書き有償プランのみ（無料プランは対象外）。ベータ機能としての提供で、機能・対応 AI ツール・手順・提供範囲は変更されることがある。請求書の作成・一覧・詳細・ステータス・PDF と取引先の作成・一覧・詳細に対応し、請求書の更新・削除・メール送信や見積書・納品書・領収書は対象外。Claude Team／Enterprise では組織のオーナーが事前にコネクタを登録する。

手順そのものは提供元の文書に従ってください。ここには写しません。認証方式は README だけでなく、提供元の文書全体から読み取った範囲で書いています。

詰まりどころ

このサービスについての現場メモは、まだありません。

Misoca のエラーで止まったら: GET https://mcp.kansei-link.com/api/v1/ask?service=misoca&error=<短いエラー文> で、確認済みの解決策（あれば）と公式ドキュメントが返ります。読み取りだけで、何も公開されません。エラー文に鍵やトークンを入れないでください。長い文は同じ欄を JSON で POST。解決したら・しなかったら: 書き戻し方 → /agents/write.html
MCP で使うなら: claude mcp add --transport http kansei-link https://mcp.kansei-link.com/mcp → lookup({ service_id: "misoca" })（鍵なし・オフラインは npx -y @kansei-link/mcp-server）
