LINE WORKS MCP｜公式サーバーの有無とつなぎ方（2026年10月時点）

LINE WORKS（LINE WORKS株式会社）の公式 MCP サーバーについて、2026-10-22 に一次資料で確かめた範囲を書いています。

公式 MCP あり
LINE WORKSには、提供元のLINE WORKS株式会社が公開する公式の MCP サーバーがあります（2026-10-22 確認）。 App Directory の「WORKS MCP」（Made by LINE WORKS）として提供されています。

公式 MCP サーバーの所在とつなぎ方

提供元LINE WORKS株式会社
所在接続先の URL は公開されておらず、管理者がアプリを追加した後のスタートガイドで案内されます
提供の形提供元が運用するサーバーに接続する（リモート）
管理者画面で「WORKS MCP」アプリを追加し、メンバー・使える機能・マスキングの規則を設定する形。
認証方式メンバーが LINE WORKS アカウントでログインして接続を認証する（App Directory の「はじめ方」の記載）。
OAuth などプロトコル上の認証方式は公式の情報に書かれていません。開発者向けサイトの OAuth 2.0 の文書は一般の API 向けで、MCP には触れていません。
公式の手順App Directory: WORKS MCP（はじめ方）
但し書きAI サービス側が MCP 接続に対応している必要がある（ChatGPT・Claude を例示）。メール・カレンダー・タスクの参照と登録。マスキングはパターンに基づくもので保証はない。使える機能はプランと管理者の権限設定による。

手順そのものは提供元の文書に従ってください。ここには写しません。認証方式は README だけでなく、提供元の文書全体から読み取った範囲で書いています。
