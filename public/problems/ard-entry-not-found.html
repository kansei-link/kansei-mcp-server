PROBLEM TYPE · HTTP 404

ARD のエントリが見つからない（ard-entry-not-found）

type: https://kansei-link.com/problems/ard-entry-not-found

何が起きたか

/ard/entries/<service_id>.json に渡した service_id のエントリが、私たちの一覧にありません。文法は合っているが、その id の記録が無い、という意味です。

次に何をするか

・一覧（/.well-known/ard.json）の url をそのまま使ってください。id を自分で組み立てると外れることがあります。
・探しているサービスが一覧に無いのは、私たちが一次資料で公式の MCP を確かめられていない、というだけです。そのサービスに MCP が無いという意味ではありません。
・人間向けの一覧は /ard/。

このエラーを報告する時

応答の X-Request-Id ヘッダ（本文の instance の urn:kansei:request: の後ろと同じ値）を添えてください。私たちの記録から同じ要求を探せます。

この型のエラーに紐づく現場メモ

まだ無い。

応答の形は RFC 9457（application/problem+json）です。もう一つの型: bad-request
