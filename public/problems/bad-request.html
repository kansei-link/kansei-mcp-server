PROBLEM TYPE · HTTP 400

要求の形が合っていない（bad-request）

type: https://kansei-link.com/problems/bad-request

何が起きたか

経路が /ard/entries/<service_id>.json の形になっていないか、service_id が文法（英小文字・数字・ハイフン、先頭は英小文字か数字、64 字まで）に合っていません。

次に何をするか

・末尾の .json を付けてください。
・id は /.well-known/ard.json の各エントリの url に入っている物をそのまま使ってください。
・経路の定義は /ard/openapi.json（OpenAPI 3.1）にあります。

このエラーを報告する時

応答の X-Request-Id ヘッダ（本文の instance の urn:kansei:request: の後ろと同じ値）を添えてください。私たちの記録から同じ要求を探せます。

この型のエラーに紐づく現場メモ

まだ無い。

応答の形は RFC 9457（application/problem+json）です。もう一つの型: ard-entry-not-found
